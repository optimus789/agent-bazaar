# Registration files

Generated by `pnpm --filter @bazaar/identity gen-registrations` (see `packages/identity/scripts/gen-registrations.ts`).

These are **placeholders**: `nativeId` uses literal strings `0.0.PROVIDER_ACCOUNT_ID` / `0xPROVIDER_ADDRESS` because the real Hedera account and EVM address don't exist until WP00's keys are generated. The `did` (HCS-14 UAID) hash is therefore **not the one that will actually be registered** — do not treat these files as final.

Once WP00 keys exist, regenerate with the real native ids and register on-chain with `packages/identity/src/cli.ts register`, which builds the file, writes it to this directory, and calls `IdentityRegistry.register(tokenUri)`. Record the resulting agentId and tx hash in `docs/STATUS.md` under WP04.
